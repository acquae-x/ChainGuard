# 05 前端视觉与交互规范（§16）

> 定位：企业生产工具，不是营销官网，不是比赛大屏。判断标准——采购员每天用 4 小时不累，老板每周看 10 分钟能懂。

## 1. 主题与色彩（写入 antd theme token，`src/theme.ts` 唯一出口）

| 语义 | 色值 | 用途 |
|---|---|---|
| 主色 primary | `#1B4F9C`（稳重蓝） | 主按钮、选中态、链接 |
| 风险红 error | `#CF1322` | 高风险、超时、驳回。**只留给风险语义**，删除类操作用默认 danger 即可，避免全页飘红 |
| 预警橙 warning | `#D46B08` | 中风险、临期、待处理 |
| 正常绿 success | `#389E0D` | 低风险已控、通过、完成 |
| 信息蓝 info | `#0958D9` | 中性提示、观察中 |
| 中性灰 | antd 默认灰阶 | 文本/边框/禁用/背景 `#F5F6F8` |

- 风险等级必须「颜色 + 图标 + 文字」三重编码（色盲可用）：高🔴▲ / 中🟠● / 低🔵▼，统一封装 `<RiskTag level/>`。
- 图表配色：分类序列用低饱和企业色板（蓝灰绿棕紫），红橙绿只用于风险语义，禁止彩虹图。
- 禁止：渐变大背景、深色驾驶舱风、装饰性动效、自动轮播。动效只允许 antd 默认过渡。

## 2. 组件使用铁律

| 场景 | 用什么 | 说明 |
|---|---|---|
| 一切列表 | ProTable | 统一 size=middle、列设置、密度切换；行高不小于 40px |
| 筛选 | 常用 3–4 项 LightFilter 顶部常驻，其余进「高级筛选」抽屉 | 筛选条件以 Tag 形式回显，可单个删除 |
| 状态 | Tag/Badge | 全站状态枚举与色一一对应，维护在 `src/constants/status.ts`，禁止散写 |
| 查看/轻编辑 | **抽屉（Drawer）优先** | 表格行点开一律抽屉，保留列表上下文，减少页面跳转 |
| 弹窗 Modal | 仅二次确认、单字段输入 | 禁止 Modal 套 Modal；复杂内容一律抽屉或整页 |
| 分步流程 | Steps | 注册/向导/导入/事件状态 |
| 审批流展示 | Steps(垂直) + 头像 | 谁批过、卡在谁 |
| 时间线 | Timeline | 事件经过、操作记录 |
| KPI | StatisticCard | 数字+同比箭头 |
| 引导 | Tour | 仅向导第 6 步和首次进入核心页 |

- 卡片 vs 表格 vs 流程图：**同构多条记录 → 表格**（风险、订单、任务列表）；**异构需对比的少量对象 → 卡片**（方案对比、KPI、行业模板）；**有先后依赖关系 → 流程/步骤**（事件状态、审批链、导入向导）。表格永远是默认，卡片必须有对比或聚合理由。

## 3. 效率细节

- 一线录入：表格支持回车跳下格、粘贴 Excel 区块（库存录入页）；表单 Enter 提交；高频操作有按钮而不是藏在「更多」。
- 管理层看险：任何风险/事件页首屏必须有等级+数字结论，详情按需展开；老板路径「登录→看到最高风险→点进→批准」≤4 次点击。
- 减少跳转：跨对象引用（供应商名、订单号）一律可点 → 打开概要抽屉（含"查看完整详情"链接），而非直接跳走。
- 全站面包屑 + 浏览器回退可用（状态存 URL query，筛选/分页/tab 都写进 URL）。

## 4. 四态设计（每个页面必须实现，封装通用组件）

- **空状态** `<EmptyGuide/>`：图标 + 一句话 + 主行动按钮（如库存空 →「导入库存数据」/「使用示例数据」），区分"没数据"和"筛选无结果"（后者给"清除筛选"）。
- **加载**：列表用 ProTable 内置 skeleton；页面级用 PageLoading；按钮 loading；Agent 生成用流水灯（见 04-G）。>1s 必须有反馈。
- **错误**：接口错统一 message.error + 列表区 Result(500) 带「重试」；表单错误定位到字段。
- **无权限**：菜单直接不渲染；直达 URL → Result(403)「无权访问，联系管理员」；字段级用 `<SensitiveField/>` 脱敏；按钮无权限时**隐藏**（不置灰），避免困惑。

## 5. 移动端审批与通知（响应式最低要求）

- 审批详情页 <768px：单列布局，操作条吸底（批准/驳回大按钮），对比表横向滚动。
- 通知中心 <768px：全屏列表。告警通知点开直达事件详情移动布局。
- 其余页面小屏仅保证不破版（Pro 自适应），不做交互优化，第三优先级再上企业微信/钉钉小程序。
