## 4. 核心业务流程（Codex 需保证 4 条流程可点击走通）

```
流程1 开通：注册3步 → 创建租户 → 初始化向导6步 → 工作台
流程2 应急主流程：风险列表(告警) → 创建事件 → 事件详情 → 生成方案(多Agent对比)
       → 调整/重算 → 提交审批 → 审批人批准 → 自动拆任务 → 任务完成 → 事件关闭 → 复盘入案例库
流程3 数据：下载模板 → 上传 → 字段映射 → 校验 → 导入报告 → 列表可见
流程4 团队：管理员邀请(码/链接) → 成员加入 → 角色生效 → 菜单/字段随权限变化
```

## 5. 每页组件/按钮/数据源/状态

已在 04 文档逐页给出（布局、组件、主操作、`services/*` 接口、四态）。补充全站复用组件清单，Codex 必须先建这些再写页面：

`<RiskTag/>`（等级三重编码）、`<StatusTag/>`（全站状态枚举）、`<SensitiveField/>`（脱敏）、`<EmptyGuide/>`（空态）、`<ObjectPeek/>`（供应商/订单/物料概要抽屉）、`<DynamicField/>`（自定义字段渲染）、`<ImportWizard/>`（可嵌入的导入步骤组件）、`<ApprovalActionBar/>`（批准/驳回/重算/转交）、`<AgentProgress/>`（方案生成流水）、`<KpiCard/>`。

## 6. MVP 首屏（供应链负责人登录后所见）

```
┌ 顶部栏: Logo|企业名 | 搜索 | [+ 上报异常] | 🔔3 | 头像 ┐
├ 左菜单: 工作台/风险监控/应急事件/决策方案/任务执行/数据管理/历史案例/报表/设置
│ 内容区:
│  [黄条: 当前为示例数据，导入真实数据 →]（如适用）
│  快捷区: [待我审批(2)] [风险总览] [上报异常]
│  KPI行: 活跃风险 8 | 待审批 2 | 进行中事件 1 | 超时任务 0
│  左2/3: 风险列表Top8（等级Tag/对象/指数条/[创建事件]按钮）
│  右1/3: 供应商异常3条 + 库存预警5条
└────
```

首屏原则：无营销元素、10 秒看清今天的风险、每条风险一步可建事件。

## 7. Codex 生成与自检要求

1. 生成顺序：theme/constants/复用组件 → services+mock → 布局与路由+access → P1 精细页 → P1 普通页 → P2 骨架。
2. 每页完成后自检：路由可达？菜单权限对表？四态齐全（精细页）？状态色出自 status.ts？敏感字段走 SensitiveField？
3. 最终自检脚本要求：`npm run build` 零 error；提供 `docs/route-access-map.md`（自动生成路由×角色表，供人工比对 02/03 矩阵）。
