# ChainGuard 复赛脚本

## 场景
台风导致港口停运，关键物料库存告急。系统接入库存、供应商、运输、订单和经验，生成应急决策。

## Step 1-7
展示库存风险、事件卡片、三类 Agent、冲突检测、反驳、仲裁和经验卡。方案由数据、权重和规则计算。

## Step 8-11
展示可行组合、系统效用、辩论收敛、历史引用、解释和审计 JSON。高风险或不收敛时人工审批。

## 敏感性
展示 current_stock 从 720 到 7200 时风险下降。企业用历史数据校准权重和阈值，不全量入模。

## 问答
- 高风险：`human_approval=True`。
- 出错：`run_failure_case()` 写 error audit。
- 数据驱动：看 ablation 与 sensitivity。
- 大历史数据 T13 分区、分批、增量校准。
