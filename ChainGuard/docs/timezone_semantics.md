# 租户时区与日历指标口径

所有业务时间戳以 UTC 保存；`tenants.timezone` 保存 IANA 时区（例如 `Asia/Shanghai`），只用于展示和日历边界。

- 今日：租户当地时间 00:00（含）至次日 00:00（不含）。
- 本周：租户当地周一 00:00（含）至下一周一 00:00（不含），不是“过去 7×24 小时”。
- 本月与报表月序列：租户当地公历月；“近 N 个月”从含当前月在内的第 N 个当地月首日开始。
- 逾期这类绝对截止时间比较仍以 UTC instant 比较，不人为移动截止时刻。

迁移对无法可靠推断属地的既有租户使用 `UTC`，以保持既有统计窗口不变；已知位于上海的 `tenant-demo` 在迁移中明确设为 `Asia/Shanghai`。注册接口接受并校验 IANA 时区。

报表导出及 API 报表窗口均采用被导出 tenant 的时区，并在 `window.timezone` 中回显。将某个 tenant 从 UTC 配置为非 UTC 后，历史记录不会被重写，但跨当地日/周/月边界的历史指标会被重新归类；UI 和导出须标注“按租户时区统计”及生效日期。
