### 2. 4 条核心流程无死链 —— ✅ 通过

- 流程1 开通：`/user/register`（3 步）→ `registerTenant`（tenant.status=initializing）→ 登录跳 `/onboarding`（6 步：行业模板/模块/导入(内嵌 ImportWizard)/阈值/邀请/演练 Tour）→ `startDrillIncident` → `/dashboard`。链路完整。
- 流程2 应急主流程：风险列表「创建应急事件」/「合并创建」→ `workflowStore.createIncident` → `/incident/:id` →「生成决策方案」→ `/decision/generate/:incidentId`（AgentProgress → 3 方案卡/对比表）→ 调整→`recalc`（成本+4%、"已修改待重算"痕迹）→ 提交审批 → `/decision/approval?tab=pending` → 批准 → 自动拆 5 个角色任务 → `/task/all` → 任务完成 → 关闭事件（status=reviewing 复盘）→ 审批时勾选「存为经验」→ `saveExperience` 入经验卡片库。全链路状态机（发现→评估→方案→审批→执行→复盘）与审计日志贯通。
- 流程3 数据导入 5 步：选类型→上传（SheetJS 真实解析）→字段映射（别名+编辑距离预匹配、必填校验）→校验预览（必填/类型/枚举/重复 + 错误报告下载）→结果报告→「查看数据列表」跳 `/data/{type}`。完整。
- 流程4 团队：`/settings/users`「生成邀请链接」→ `/user/join?code=CGDEMO01`（邀请码预填）→ `joinTenant`（buyer 角色）→ setInitialState → 菜单/按钮/字段随 access.ts 权限即时生效。完整。

### 3. 权限矩阵逐项比对 —— ✅ 通过（1 处修复）

- `docs/route-access-map.md` 与构建重新生成版本 **diff 一致**；路由级与 03 文档角色×菜单矩阵逐格核对相符（admin 无任务菜单、boss/finance 无数据管理、warehouse 无决策/案例/报表、settings 按 boss=审计only / scm_lead=审批流+阈值 / auditor=审计only 裁剪）。
- **buyer×审批中心疑点结论：不是权限泄漏**。buyer 走 `canDecision` 可进 `/decision/approval`（03 菜单矩阵「决策方案」buyer=✅），但审批动作按钮由 `canApproveLow/Medium/High/canSubmitHigh/canCountersign` 五路控制，buyer 全为 false → `<Access>` fallback 显示「当前角色仅可查看审批记录」，列表中成本影响列走 `<SensitiveField field="cost">` 显示 ***。route-access-map 补充规则第 2、3 条已如实记载。
- 重点抽查：
  - buyer 成本=***：buyer 权限无 `field:cost:view`/`field:supplierPrice:view`/`field:profit:view`，所有成本类展示均经 SensitiveField ✅
  - auditor 全只读：`readonly=true` 关闭 canManageRisk/canManageIncident/canModifyDecision/canTaskWrite/canApproval 及「新建」按钮 ✅
  - admin 无审批按钮：canApprove* 均 `&& !isAdmin` ✅；admin 无上报异常按钮：admin 无 `risk:event:create`，顶部栏与工作台按钮均按该码隐藏 ✅
- **修复（原为一般级权限泄漏）**：`access.canExport` 混用 `data:export|audit:export`，导致 auditor（仅审计导出权）在数据管理各页看到「导出」按钮，违反 02 矩阵「导出数据 auditor=✅(审计)」。已拆分为 `canExportData` / `canExportAudit`，数据页与审计页分别改用；并按 02 §6「导出：auditor 可导出 CSV」移除 admin 冗余的 `audit:export` 码。

### 4. 敏感字段全走 `<SensitiveField/>` —— ✅ 通过

- grep 全站无手写 `'***'` 脱敏；出现 cost/profit/contract/customerLevel/supplierPrice 数值展示的 11 个页面/组件（含全局搜索抽屉、经验卡片效果列、KPI 敏感卡）全部经 `<SensitiveField/>`；组件实现与 02 §4 一致（*** + 锁图标 + Tooltip「无权限查看，请联系管理员」，按 `field:*:view` 码放行）。
